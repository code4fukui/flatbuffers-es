# flatbuffers-es

An ES module version of the official [google/flatbuffers](https://github.com/google/flatbuffers) library, designed for modern JavaScript environments like browsers, Deno, and Node.js.

## Demo

- [Read a `monster.bin` file in the browser](https://code4fukui.github.io/flatbuffers-es/es/example/)

## Features

-   **ES Module Native:** Directly importable in browsers and modern runtimes without a bundler.
-   **High Performance:** Access serialized data with zero parsing or unpacking, leveraging the memory efficiency of FlatBuffers.
-   **TypeScript Ready:** Works seamlessly with code generated by the `flatc` compiler's TypeScript generator.
-   **Cross-Platform:** Create and read binary data that is compatible with all other languages supported by FlatBuffers (C++, Java, Python, Rust, etc.).

## Prerequisites

-   The `flatc` compiler from the main [google/flatbuffers](https://github.com/google/flatbuffers) project.
-   A JavaScript runtime that supports ES modules (e.g., Deno, Node.js, or a modern web browser).
-   (Optional) The TypeScript compiler (`tsc`) to convert generated code to JavaScript.

## Usage

The workflow involves two main steps: generating code from your schema and then using that code in your application.

### 1. Code Generation

First, you need to generate TypeScript code from your FlatBuffers schema (`.fbs`) file. The generated code will import the `flatbuffers` module, so you'll need to compile it against a local copy of this library.

```bash
# Step 1: Generate TypeScript from your schema.
# The --ts-flat-files flag is recommended to output a single file.
flatc --ts --ts-flat-files monster.fbs

# Step 2: Download the flatbuffers-es module as a local file.
deno bundle https://code4fukui.github.io/flatbuffers-es/es/index.js > flatbuffers.js

# Step 3: Patch the generated file to import the local module.
# (On macOS/Linux, `sed` works well. On Windows, you may need to edit the file manually.)
sed -i "s/'flatbuffers'/'.\/flatbuffers.js'/" monster_generated.ts

# Step 4: Compile the generated TypeScript to JavaScript.
tsc --target es2020 --module es2020 monster_generated.ts
```

You will now have `monster_generated.js` and `flatbuffers.js` ready to be used in your application.

### 2. Application Code

You can now import and use the generated code to read your binary FlatBuffers data. This example works in both browsers and Deno.

```javascript
// Import the flatbuffers-es runtime and your generated code.
import * as flatbuffers from "https://code4fukui.github.io/flatbuffers-es/es/index.js";
import * as Sample from "./monster_generated.js";

// Create a namespace alias for your game data.
const MyGame = { Sample };

// Fetch the binary data and wrap it in a ByteBuffer.
const response = await fetch("./monster.bin");
const bytes = new Uint8Array(await response.arrayBuffer());
const buf = new flatbuffers.ByteBuffer(bytes);

// Access the root object of the FlatBuffer.
const monster = MyGame.Sample.Monster.getRootAsMonster(buf);

// Read data from the monster object.
const hp = monster.hp();
const mana = monster.mana();
const name = monster.name();

console.log({ hp, mana, name }); // { hp: 80, mana: 150, name: "Orc" }
```
